ARCHITECTURE HIGHLIGHTS
=======================

1. DeterministicLLMEngine
   - Main public API
   - Coordinates cache, ledger, offline fallback
   - Async/await with tokio
   - Thread-safe Arc<Mutex> for shared state

2. PromptCache (SHA256 Fingerprinting)
   - DashMap<String, CachedInferenceResponse>
   - LRU eviction when capacity exceeded
   - TTL-based expiration (24-hour default)
   - O(1) lookup time, thread-safe

3. MerkleChainLedger (L8 Proof Integration)
   - Ed25519 signatures on every entry
   - Merkle chain linking (prev_hash → current_hash)
   - Verification method validates chain integrity
   - Cloneable for concurrent sharing

4. OfflineFallback (Rule-Based)
   - DashMap<domain, OfflineFallbackTemplate>
   - Pattern matching with case-insensitive search
   - Graceful degradation when API unavailable
   - Supports multiple fallback strategies

5. TokenCostMetrics
   - Baseline tracking (cost if no caching)
   - Actual tracking (cost with caching)
   - Reduction percentage calculation
   - Offline fallback counting

USAGE EXAMPLE
=============

use l0_deterministic_llm::{DeterministicLLMEngine, DeterministicInferenceRequest};
use ed25519_dalek::SigningKey;

#[tokio::main]
async fn main() {
    let mut seed = [0u8; 32];
    let signing_key = SigningKey::from_bytes(&seed);
    let engine = DeterministicLLMEngine::new(signing_key);

    // Register offline fallback
    engine.register_fallback_template(
        "credit".to_string(),
        "credit score".to_string(),
        "Default score: 650".to_string(),
    ).unwrap();

    // Make inference request (temperature=0.0 enforced)
    let request = DeterministicInferenceRequest::new(
        "What is the credit score?".to_string(),
        100,
        "claude-3-opus".to_string(),
    );

    match engine.infer(request).await {
        Ok(response) => {
            println!("Output: {}", response.output);
            println!("Tokens: {}", response.total_tokens);
            println!("Cache hit: {}", response.cache_hit);
        }
        Err(e) => eprintln!("Error: {}", e),
    }

    // Check metrics
    let metrics = engine.metrics();
    println!("Cache hit rate: {:.2}%", metrics.cost_reduction_percent);
    println!("Total inferences: {}", metrics.total_inferences);

    // Verify ledger integrity
    let is_valid = engine.verify_ledger().unwrap();
    assert!(is_valid);
}
