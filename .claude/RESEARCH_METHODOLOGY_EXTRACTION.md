## Protocol Enhancement v1.1 Proposal

### New Step: Pre-Research Methodology Check

**Before launching research agents, answer:**

1. **Vision Check:**
   - [ ] Can I state this insight in <20 words?
   - [ ] Does it converge 3+ independent signals?
   - [ ] Is it contrarian (does it go against market consensus)?

2. **Reality-Check Stance:**
   - [ ] What would invalidate this idea?
   - [ ] Where is the market NOT yet?
   - [ ] What do competitors have that we lack?

3. **Research Angle Selection (Pre-Search):**
   - [ ] Technical feasibility (can we build this?)
   - [ ] Market demand (will customers pay?)
   - [ ] Convergence validation (do 5 sources align?)

### New Step: Triple-Model Research

**Use all three AIs in sequence:**

1. **Perplexity Pass:** Web reality-check (what's actually deployed in May 2026?)
2. **Opus Pass:** Architecture check (does this fit SMAOS 13 layers?)
3. **Notebook Pass:** Strategic check (does this align with agentic AI futures?)

**Conflict Resolution:** If the three disagree, that's the real finding (not the consensus).

### New Step: Codebase Validation

**Before approving decision:**
- [ ] Can this be built with existing repo patterns?
- [ ] How many lines of new code? (If >500 new LOC, requires Phase plan)
- [ ] Does this require new dependencies? (If yes, architect first)
