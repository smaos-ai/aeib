## Slide 26: Appendix: Merkle-DAG Technical Summary

**Why Merkle-DAG for AI Governance?**

Traditional audit logs = sequential text files (mutable, trust-dependent)  
SovereignNexus Merkle-DAG = cryptographic hash tree (immutable, tamper-proof)

**Structure:**
```
Root Hash: SHA-256(Transactions 1..N)
├── Level 2: Hash(T1–T8) | Hash(T9–T16) | Hash(T17–T24)
├── Level 1: Hash(T1–T4) | Hash(T5–T8) | ... 
└── Leaves: [T1] [T2] [T3] ... [TN]
```

**Property:** Change any transaction → root hash changes → signature breaks → evidence public.
