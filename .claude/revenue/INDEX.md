## Monthly Update Checklist

**First 5 business days (Revenue Close):**
- [ ] Update REVENUE_TRACKING_SHEET.csv with actual revenue, customer adds/churn
- [ ] Reconcile with finance system (invoices, payments, adjustments)
- [ ] Calculate actual MRR vs. forecast

**Day 10 (Executive Review):**
- [ ] Run REVENUE_METRICS_DASHBOARD.md metrics (MRR, customer count, retention, CAC, margins)
- [ ] Variance analysis (if >5% variance, complete RCA)
- [ ] Sensitivity check (which assumptions changed?)
- [ ] Risk assessment (any yellow/red flags from contingency triggers?)

**Day 15 (Board Communication):**
- [ ] Update EXECUTIVE_SUMMARY_ONE_PAGER.md with actual results
- [ ] Prepare 1-pager for board/investor communication
- [ ] Escalate any >15% variance (requires strategy discussion)

**Day 20 (Forecast Refresh):**
- [ ] Update REVENUE_FORECAST_DETAILED.md for next month
- [ ] Adjust pipeline timing if needed (based on sales stage changes)
- [ ] Update sensitivity analysis (downside/base/upside cases)
