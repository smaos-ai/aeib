## HOW TO USE THESE FILES

### For Email Send (June 26)
1. Open `investor_list_50.json` → Extract email addresses + personalization fields
2. Open `wedge_emails_50.md` → Copy email text for investor
3. Insert Calendly link (unique per investor)
4. Send via email service provider (with tracking enabled)
5. Update CRM: `email_sent_date` in `crm_metadata.json`

### For Follow-Ups (June 27-29)
1. Check `crm_metadata.json` → Identify non-responders
2. Pull template from `follow_up_templates.md` (Wave N)
3. Personalize template (investor name, past bet, mutual contact)
4. Send on schedule per `email_queue_schedule.md`
5. Update CRM: `follow_up_N_sent` status

### For Meeting Management
1. Track all Calendly bookings → Update `crm_metadata.json`
2. Store meeting notes in CRM
3. Prepare pitch materials (deck + one-pager)
4. Schedule pre-call warm-up (15 min before meeting)
5. After meeting: Update CRM (`meeting_attended`, `meeting_notes`, `term_sheet_interest`)

### For Post-Campaign Analysis (July 1)
1. Pull metrics from email provider (open rates, clicks)
2. Pull Calendly data (booking rate, attendees)
3. Compile final report → `crm_metadata.json`
4. Calculate conversion rates (email→meeting→term sheet)
5. Document lessons learned for Series B
