## TROUBLESHOOTING & ERROR HANDLING

### Error 1: "Document Format Invalid"
**Symptom:** Claims file upload rejected
**Cause:** Format doesn't meet WIPO standards
**Fix:**
1. Verify claims are numbered 1-7
2. Each claim starts on new line with "Claim 1:", "Claim 2:", etc.
3. Remove all markdown formatting (#, **, etc.)
4. Save as plain `.txt` file
5. Re-upload

### Error 2: "Abstract Exceeds 150 Words"
**Symptom:** Abstract upload rejected
**Cause:** WIPO word count algorithm flagged as too long
**Fix:**
1. Count words in abstract (target: 145 words max)
2. Remove adjectives, simplify language
3. Focus on core innovation only
4. Re-save and re-upload

### Error 3: "Payment Authorization Failed"
**Symptom:** Credit card declined
**Cause:** Card limit, fraud detection, or invalid info
**Fix:**
1. Verify card is active (call your bank)
2. Confirm billing address matches card records
3. Try different card if available
4. Contact WIPO support: pct.ipo@wipo.int
5. Request payment by bank transfer as fallback

### Error 4: "Payment Processed but No Receipt Generated"
**Symptom:** Payment confirmed, but filing receipt page not loading
**Cause:** System timeout or network issue
**Fix:**
1. DO NOT close browser or refresh
2. Wait 5 minutes (WIPO system may still be processing)
3. If still no receipt: Email WIPO support with transaction ID
4. They will manually generate receipt
5. Contact: pct.ipo@wipo.int
