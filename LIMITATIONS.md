**Standard:** Agent-Effect Integrity Benchmark (AEIB) v0.1.0  
**Scope:** Offline Synthetic Action Uncertainty Evaluation

## 📄 Adopted Release Statement

> **AEIB v0.1.0 release candidate verification**
> 
> AEIB v0.1.0 is a deterministic, offline benchmark over ten synthetic JSONL scenarios and six declared dispositions. The release was executed twice in a clean environment using the declared command and produced identical console output and artifact digests. The verification covered archive integrity, fixture execution, precedence behavior, and expected-output comparison.
> 
> These results demonstrate reproducibility of the released benchmark package under the stated environment. They do not establish production security, DORA compliance, external-ledger truth, regulatory classification, or universal agent safety.

3. **Not an incident classification:**

4. **Not proof of external-system truth:**
