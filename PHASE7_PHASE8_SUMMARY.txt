     - ExplainabilityAPI class (REST endpoint integration)
     - Demo implementation (working end-to-end)

Implementation Details:

  SHAPExplainer:
    - Computes SHAP values (Shapley additive explanations)
    - Generates waterfall plots for feature importance
    - Shows cumulative contribution of each feature
    - Features: credit_score, income, employment_years, DTI, payment_history, etc.
  
  LIMEExplainer:
    - Local interpretable model-agnostic explanations
    - 1000 perturbations per decision
    - Fits local linear regression for feature weights
    - Identifies top 3 driving features
    - Provides human-readable interpretation
  
  ExplainabilityReporter:
    - Combines SHAP (global) + LIME (local) explanations
    - Saves to ledger directory (/tmp/decision_explanations/<receipt_id>/)
    - Generates "Why?" button HTML for UI integration
    - Creates executive summaries
  
  ExplainabilityAPI:
    - REST endpoint: /api/explain/{receipt_id}
    - Retrieves explanation from ledger
    - Returns JSON with SHAP + LIME data
    - Ready for browser integration
