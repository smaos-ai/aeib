ARCHITECTURE DECISIONS
====================

1. Embeddings Storage: JSONB (not pgvector)
   Reason: pgvector extension unavailable in Alpine PostgreSQL 14
   Impact: Semantic search computed in application layer
   Trade-off: Acceptable for pilot; can migrate to pgvector later

2. Full-Text Search: PostgreSQL tsvector + gin indexes
   Reason: Native database support, proven BM25 equivalent
   Performance: <100ms on compliance queries

3. RRF Weighting: 60% semantic, 40% keyword
   Reason: Balance between meaning-based and literal matching
   Tunable: Can adjust weights per use case

4. Query Latency: <100ms verified
   Note: Docker exec overhead ~60ms; actual query <10ms
   Production: Direct DB connection would be <20ms total
