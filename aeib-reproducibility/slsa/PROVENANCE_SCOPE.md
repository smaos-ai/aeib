# SLSA Provenance Scope & Canonical Release Artifact Set

## 1. Scope Definition (Option B)
The provenance attestation generated by `slsa-framework/slsa-github-generator` binds the following canonical release artifacts:

1. **Verifier Distribution**: Standalone offline verifier distribution (`aeib-verifier.tar` and `install/aeib-verifier`) containing the compiled CLI launcher and bundled runtime dependencies.
2. **CycloneDX SBOM**: `bom.json` machine-readable inventory of all dependencies, versions, and licenses.
3. **Execution Receipt**: `receipt.json` produced by the unsimulated Gate 4 socket fault injection test.
4. **Ledger Public Key**: `ledger-public.pem` corresponding to the signing key used in `receipt.json`.

## 2. Gradle Task and Project Mapping
- **Project Name**: `:aeib-verifier` under root project `aeib-native-runtime`.
- **Packaging Task**: `gradle -p aeib-native-runtime :aeib-verifier:installDist :aeib-verifier:distTar`
  - Installs to: `aeib-native-runtime/aeib-verifier/build/install/aeib-verifier/`
  - Archives to: `aeib-native-runtime/aeib-verifier/build/distributions/aeib-verifier.tar`
- **SBOM Task**: `gradle -p aeib-native-runtime cyclonedxBom`
  - Output: `aeib-native-runtime/build/reports/bom.json`
- **Test Task**: `gradle -p aeib-native-runtime clean test`
  - Output: `aeib-native-runtime/build/test-results/receipt.json` and `ledger-public.pem`

## 3. Canonical Staging and Hashing
All artifacts are assembled into `release-artifacts/` prior to subject calculation:
```bash
mkdir -p release-artifacts
cp -a aeib-native-runtime/aeib-verifier/build/install/aeib-verifier release-artifacts/
cp aeib-native-runtime/aeib-verifier/build/distributions/aeib-verifier.tar release-artifacts/ 2>/dev/null || true
cp aeib-native-runtime/build/reports/bom.json release-artifacts/
cp aeib-native-runtime/build/test-results/receipt.json release-artifacts/
cp aeib-native-runtime/build/test-results/ledger-public.pem release-artifacts/

FILES=$(find release-artifacts -type f | sort)
HASHES=$(sha256sum $FILES | base64 -w0)
```
