# SLSA Generator Input Contract

Generator: slsa-framework/slsa-github-generator
Pinned version: v2.1.0
Workflow: generator_generic_slsa3.yml
Input: base64-subjects

Required encoding:
"Artifacts for which to generate provenance, formatted the same as the output of sha256sum (SHA256 NAME\n[...]) and base64 encoded."

Required subject format:
<sha256-hash>  <filename>
Standard output format generated by `sha256sum` (two spaces separating hash and filename, newline-delimited for multiple subjects), base64-encoded.

Valid example:
sha256sum build/libs/aeib-core.jar aeib-verifier/build/install/aeib-verifier/bin/aeib-verifier | base64 -w0

Invalid formats:
- Unencoded raw `sha256sum` text output
- Multi-line base64 encoding with line wraps (must use `base64 -w0` or `tr -d '\n'`)
- JSON subject arrays or non-sha256sum formatted strings
