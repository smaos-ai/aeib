# 1-Day Outcome-Integrity Diagnostic Harness

This package provides enterprise financial and IAM candidates a 1-day evaluation harness for measuring post-dispatch ambiguity in their current AI orchestrator implementations.

## Contents
1. `diagnostic_baseline.py` - Establishes request RTT and idempotency baselines.
2. `fault_matrix.py` - Simulates transport failures (504s) to evaluate C2 semantic drift.
3. `pg_probe_adapter.py` - Enterprise PostgreSQL adapter for out-of-band ground truth resolution.
