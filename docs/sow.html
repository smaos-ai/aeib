1. Objective

To evaluate the evidence-integrity of the Client’s autonomous agent harnesses under simulated wire-fault conditions (e.g., HTTP 504 Gateway Timeout, TCP Reset). This diagnostic is performed entirely locally on Client infrastructure to ensure zero data egress, identifying instances where agent SDKs falsely log CONFIRMED when external settlement evidence is absent.

2. Scope of Work

SovereignNexus s.r.o. will execute the following using the smaos-audit local verification engine:

  • Classification: Evaluate agent responses against the 6-state precedence taxonomy (CONFIRMED, REFUSED, UNKNOWN, CONFLICT, MISSING_EVIDENCE, INVALID_INPUT).
