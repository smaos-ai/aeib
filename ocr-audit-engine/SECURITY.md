# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within OCR Audit Engine, please send an email to `andrejlo123@gmail.com`.
Please do not report security vulnerabilities through public GitHub issues.

We acknowledge receipt within 24 hours and provide regular status updates until the vulnerability is addressed.
