CODE FLOW (ZERO BLOCKING)
================================================================================

REQUEST:
  ├─ input: GovernRequest(action, blast_radius, user_approved)
  └─ includes: request_id, user_id, app_id, timestamp

PRE-EXECUTION CHECK:
  ├─ Step 1: Classify risk level from blast_radius
  │   └─ RiskLevel.from_blast_radius(0.0-1.0)
  │
  ├─ Step 2: Check PSI drift auto-gate
  │   └─ if psi > 0.25 AND not human_approved → BLOCKED
  │
  ├─ Step 3: Check risk level approval requirement
  │   └─ if HIGH|CRITICAL AND not human_approved → BLOCKED
  │
  └─ Step 4 (BLOCKED): Return fail-closed response
     ├─ allowed: false
     ├─ charge_amount: 0 (ZERO CHARGE)
     ├─ error: "HumanGateRequired" | "DriftGateRequired"
     └─ reason: detailed explanation

APPROVAL:
  ├─ Step 5: Gate passes
  ├─ Generate Merkle proof
  ├─ Update cumulative Merkle root
  └─ Step 6 (APPROVED): Return success response
     ├─ allowed: true
     ├─ charge_amount: 100 (AP2 units)
     ├─ proof: HumanGateProof
     │   ├─ merkle_root: SHA256 hash
     │   ├─ timestamp: ISO 8601
     │   ├─ decision_id: request_id
     │   ├─ approved_by: user_id (if human)
     │   └─ auto_approved: bool
     └─ reason: "Approved (risk: [LEVEL])"
