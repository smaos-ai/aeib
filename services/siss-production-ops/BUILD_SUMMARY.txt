API ENDPOINTS
=============

Metrics Routes (GET /api/metrics)
  - /api/metrics           : Export Prometheus metrics
  - POST /api/metrics/cpu  : Record CPU usage
  - POST /api/metrics/memory : Record memory usage

Alerts Routes (POST /api/alerts)
  - POST /api/alerts/evaluate/latency   : Evaluate latency alert
  - POST /api/alerts/evaluate/error-rate : Evaluate error rate alert
  - POST /api/alerts/evaluate/compliance : Evaluate compliance alert
  - GET /api/alerts/history : Get alert evaluation history

Incidents Routes (/api/incidents)
  - POST /api/incidents/create : Create PagerDuty incident
  - GET /api/incidents : List all incidents
  - GET /api/incidents/:id : Get incident details
  - POST /api/incidents/:id/resolve : Resolve incident

Runbooks Routes (/api/runbooks)
  - GET /api/runbooks : List available runbooks
  - GET /api/runbooks/:alert_type : Get runbook for alert type

System Routes
  - GET /health : Health check endpoint

EXAMPLE USAGE
=============
# Record metrics
curl -X POST http://localhost:3000/api/metrics/cpu -H "Content-Type: application/json" -d '{"value": 45.5}'

# Export Prometheus metrics
curl http://localhost:3000/api/metrics

# Evaluate alert
curl -X POST http://localhost:3000/api/alerts/evaluate/latency \
  -H "Content-Type: application/json" \
  -d '{"p95": 600, "threshold": 500}'

# Create incident
curl -X POST http://localhost:3000/api/incidents/create \
  -H "Content-Type: application/json" \
  -d '{"title":"Latency Breach","severity":"critical","service_id":"api-gateway","description":"P95 > 500ms"}'

# Get runbook
curl http://localhost:3000/api/runbooks/latency_breach
